# Publish this project for Rocket.new

This archive already contains a Next.js + TypeScript application at its root.

## Important

- Extract this archive on your computer before publishing it to GitHub.
- Do not upload this ZIP as a file inside the repository.
- Do not commit `.env` or `.env.local`.
- Add environment variables privately in Rocket.new after importing.

## GitHub Desktop steps

1. Open GitHub Desktop and clone `hpspublication1-lab/final-project-`.
2. Open the cloned repository folder.
3. Delete `samyakceemastery (7).zip` from the cloned folder.
4. Copy all files and folders from this extracted package into the cloned repository root.
5. In GitHub Desktop, commit with the message `Publish Next.js TypeScript application`.
6. Click **Push origin**.
7. Confirm that `package.json`, `tsconfig.json`, `src`, and `public` are visible on the GitHub repository homepage.
8. In the new Rocket.new account, choose **Build → From GitHub** and select the repository.

## Required private environment variables

Use `.env.example` as the variable-name checklist. Enter the actual values in Rocket.new project settings; never paste them into GitHub.
